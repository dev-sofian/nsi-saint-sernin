## Les types principaux

| Type    | Exemple        | Description            |
|---------|----------------|------------------------|
| `int`   | `42`           | nombre entier          |
| `float` | `3.14`         | nombre à virgule       |
| `str`   | `"bonjour"`    | chaîne de caractères   |
| `bool`  | `True`         | vrai ou faux           |

## Affectation

Une variable est un nom qui désigne une valeur.

```python
age = 16
nom = "Alice"
print(nom, "a", age, "ans")
```

La fonction `type()` donne le type d'une valeur :

```python
print(type(3.5))   # <class 'float'>
```
